# Quiz2Slide Studio - GitHub Pages Edition 📊

A **100% Client-Side** PDF Quiz to PowerPoint presentation generator that runs entirely inside the web browser with **no backend servers or third-party cloud accounts required**.

---

## 🚀 How to Enable Live Website Link via GitHub Pages

### Step 1: Push this folder to a GitHub Repository
1. Open terminal inside this folder:
   ```bash
   cd d:\Work\kaku\pdf_quiz_gh_pages
   git init
   git add .
   git commit -m "Initial commit - GitHub Pages Quiz2Slide"
   ```
2. Create a new repository on [GitHub](https://github.com/new) named `quiz2slide` (or any name you prefer).
3. Push your files:
   ```bash
   git branch -M main
   git remote add origin https://github.com/YOUR_USERNAME/quiz2slide.git
   git push -u origin main
   ```

### Step 2: Turn on GitHub Pages (1 Click)
1. On your GitHub repository page, click **Settings** (top menu).
2. On the left sidebar, click **Pages**.
3. Under **Build and deployment** $\rightarrow$ **Branch**:
   - Select `main`
   - Select `/ (root)`
   - Click **Save**.

Within 30 seconds, GitHub will give you your **live public website URL**:
👉 `https://YOUR_USERNAME.github.io/quiz2slide/`

Anyone who visits that link will be able to upload a quiz PDF, select the slide chalkboard area visually, and download PowerPoint presentations instantly!
